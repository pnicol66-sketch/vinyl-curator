Google Drive direct upload (optional)

Nothing to set up — this copy of the app already has its Google details built in. Tap Upload to Google Drive on the save screen, sign in with your own Google account, and allow access. Your photos stay in your Drive.

The first upload into a folder offers to share that folder only, read-only, with this address, so the archive can collect your photos without you arranging anything in Drive. You stay the owner and can stop sharing at any time from Drive. Leave it empty and nothing is ever shared.

Advanced: use your own Google project

Only needed if this app came without Google details built in, or you want uploads going through a Cloud project you control. Leave every box below empty to use whatever the app ships with.

  1. Go to console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library → enable Google Drive API (and Google Picker API if you want Link…).
  3. APIs & Services → OAuth consent screen → External. The app asks only for the non-sensitive drive.file scope, so you can Publish app straight to production with no verification review — otherwise every user must be added by hand as a Test user and will see an “unverified app” warning.
  4. Credentials → Create credentials → OAuth client ID → type Web application.
  5. Under Authorized JavaScript origins add the address where this app is hosted (e.g. https://yourname.github.io).
  6. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below.
  7. For Link… only: Credentials → API key, plus the project number from the Cloud console Dashboard.
AI auto-crop — owner only

With a key set, this device sends each photo to Claude to auto-crop the cover, label or disc before you review — you just fix and Save. The key is stored only in this browser and is never shared. Leave it empty and you crop by tapping, exactly as now.

Each upload goes to the default folder unless you pick another on the save screen. New folders are created in Drive on first upload; removing one here doesn’t touch Drive.

Link… is only for a folder that already exists in Drive. You normally don’t need it — let the app create its own folder and share that, above. Link… points an entry at a folder that already exists — including one someone else owns and shared with you. Use it whenever the folder was made by hand or is shared, because this app can only see folders it created itself and would otherwise build a second, private folder of the same name. Everything you upload into a linked folder is visible to whoever that folder is shared with.
